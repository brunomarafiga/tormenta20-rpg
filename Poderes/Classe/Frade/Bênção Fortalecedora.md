# ⚡ Bênção Fortalecedora

> [!t20-stats]
> - 🏷️ <span class="t20-roxo">Categoria:</span> Poder de Classe ([[Frade]])
> - 🔑 <span class="t20-amarelo">Pré-requisitos:</span> Lançar magias (Bênção)
> - 📜 <span class="t20-ciano">Fonte:</span> Deuses de Arton

Quando você lança Bênção, os aliados abençoados recebem uma quantidade de PV temporários igual a 5 vezes o bônus em testes de ataque fornecido pela magia. Esses PV temporários duram enquanto a magia durar.
