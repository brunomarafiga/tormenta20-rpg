# ⚡ Domínio Excêntrico

> [!t20-stats]
> - 🏷️ <span class="t20-roxo">Tipo:</span> Habilidade de Classe Variante
> - 🛡️ <span class="t20-verde">Classe:</span> [[Inovador]] (Variante de [[Guerreiro]])
> - 🎖️ <span class="t20-amarelo">Nível Requerido:</span> 4º Nível

A partir do 4º nível, sempre que passar pelo menos uma semana carregando uma arma exótica ou de fogo superior ou mágica, você recebe proficiência nela.
