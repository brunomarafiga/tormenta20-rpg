*Encantamento • 3º Círculo • Universal*

> [!t20-stats]
> - ⚡ <span class="t20-exec">Execução:</span> Padrão
> - 🎯 <span class="t20-alc">Alcance:</span> Curto
> - 👥 <span class="t20-area">Alvo:</span> 1 humanoide ou animal

> - 🛡️ <span class="t20-res">Resistência:</span> Vontade parcial

O alvo fica [[Paralisado]]; se passar na resistência, em vez disso fica [[Lento]]. A cada rodada, pode gastar uma ação completa para fazer um novo teste de [[Vontade]]. Se passar, se liberta do efeito.

> [!t20-pm] Aprimoramentos Canônicos
> - <span class="t20-pm">+1 PM</span> muda o alvo para 1 espírito.
> - <span class="t20-pm">+2 PM</span> aumenta o número de alvos em +1.
> - <span class="t20-pm">+3 PM</span> muda o alvo para 1 criatura. Requer 4º círculo.
