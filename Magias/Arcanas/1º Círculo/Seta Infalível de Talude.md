# 🔮 Seta Infalível de Talude
*Evocação • 1º Círculo • Arcana*

> [!t20-stats]
> - ⚡ <span class="t20-exec">Execução:</span> Padrão
> - 🎯 <span class="t20-alc">Alcance:</span> Médio
> - 👥 <span class="t20-area">Alvo:</span> Criaturas escolhidas
> - ⏳ <span class="t20-dur">Duração:</span> Instantânea
> - 🛡️ <span class="t20-res">Resistência:</span> Nenhuma

Favorita entre arcanistas iniciantes, esta magia lança duas setas de energia que causam 1d4+1 pontos de dano de essência cada. Você pode lançar as setas em alvos diferentes ou concentrá-las num mesmo alvo. Caso você possua um bônus no dano de magias, como pelo poder Arcano de Batalha, ele é aplicado em apenas uma seta (o bônus vale para a magia, não cada alvo).

> [!t20-pm] Aprimoramentos Canônicos
> - <span class="t20-pm">+2 PM</span> muda as setas para lanças de energia que surgem e caem do céu. Cada lança causa 1d8+1 pontos de dano de essência. Requer 2º círculo.
> - <span class="t20-pm">+2 PM</span> muda o número de setas/lanças para três.
> - <span class="t20-pm">+4 PM</span> muda o número de setas/lanças para cinco. Requer 2º círculo.
> - <span class="t20-pm">+9 PM</span> muda o número de setas/lanças para dez. Requer 4º círculo.
