# 🔮 Área Escorregadia
*Convocação • 1º Círculo • Arcana*

> [!t20-stats]
> - ⚡ <span class="t20-exec">Execução:</span> Padrão
> - 🎯 <span class="t20-alc">Alcance:</span> Curto
> - 🌐 <span class="t20-area">Área:</span> Quadrado de 3m ou 1 objeto
> - ⏳ <span class="t20-dur">Duração:</span> Cena
> - 🛡️ <span class="t20-res">Resistência:</span> Reflexos (veja texto)

Esta magia recobre uma superfície com uma substância gordurosa e escorregadia. Criaturas na área devem passar na resistência para não cair. Nas rodadas seguintes, criaturas que tentem movimentar-se pela área devem fazer testes de Acrobacia para equilíbrio (CD 10).

Área Escorregadia pode tornar um item escorregadio. Uma criatura segurando um objeto afetado deve passar na resistência para não deixar o item cair cada vez que usá-lo.

> [!t20-pm] Aprimoramentos Canônicos
> - <span class="t20-pm">+1 PM</span> aumenta a área em +1 quadrado de 1,5m.
> - <span class="t20-pm">+2 PM</span> muda a CD dos testes de Acrobacia para 15.
> - <span class="t20-pm">+5 PM</span> muda a CD dos testes de Acrobacia para 20.
