# 🔮 Voo
*Transmutação • 3º Círculo • Arcana*

> [!t20-stats]
> - ⚡ <span class="t20-exec">Execução:</span> Padrão
> - 🎯 <span class="t20-alc">Alcance:</span> Pessoal
> - 👥 <span class="t20-area">Alvo:</span> Você
> - ⏳ <span class="t20-dur">Duração:</span> Cena
> - 🛡️ <span class="t20-res">Resistência:</span> Nenhuma

Você recebe deslocamento de voo 12m. Voar por meio desta magia é simples como andar — você pode atacar e lançar magias normalmente enquanto voa. Quando a magia termina, você desce lentamente até o chão, como se estivesse sob efeito de Queda Suave.

> [!t20-pm] Aprimoramentos Canônicos
> - <span class="t20-pm">+1 PM</span> muda o alcance para toque e o alvo para 1 criatura.
> - <span class="t20-pm">+4 PM</span> muda a duração para um dia. Requer 4º círculo
> - <span class="t20-pm">+4 PM</span> muda o alcance para curto e o alvo para até 10 criaturas. Requer 4° círculo.
